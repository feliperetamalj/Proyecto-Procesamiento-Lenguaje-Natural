# Asistente de atención para RielSur

Proyecto del curso Procesamiento del Lenguaje Natural (UAI, 2026). Elegí la opción 3 del enunciado: un chatbot en Python que atiende a los clientes de un servicio, detecta qué necesitan y qué datos entregan, y responde sin inventar información.

El servicio es RielSur, una empresa de trenes ficticia entre Santiago y Chillán. Toda la información que el asistente puede usar (estaciones, horarios, precios, políticas y algunas reservas de ejemplo) está en `data/base_conocimiento.json`, que se genera con `scripts/construir_base_conocimiento.py`.

Solo uso modelos locales a través de Ollama.

## Estructura

```
data/        base de conocimiento
scripts/     utilidades para generar datos
```
